# Security Policy

This is a demo/portfolio project, but it models credit-reporting data flows, so
security issues are still taken seriously.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately via [GitHub Security Advisories](../../security/advisories/new)
for this repository, or by emailing jonathanl1020.jl@gmail.com.

Include:
- A description of the issue and its potential impact
- Steps to reproduce
- Any relevant logs or code references

You can expect an initial response within a few days. There is no bug bounty
for this project, but reports are appreciated and will be credited unless you
prefer otherwise.
